Developer API Documentation

REST v1

Integrate motorcycle engine diagnostics directly into onboard IoT telematics units, mobile apps, or workshop scanners using the JSON REST API.

POST /api/predict

Submits 6 engine measurements and returns model classification, probabilities, risk severity, and sensor diagnostics.

Example Request Body (JSON)

{
  "bike_model": "Yamaha R15 V4",
  "bike_year": 2023,
  "engine_rpm": 700.0,
  "lub_oil_pressure": 2.493,
  "fuel_pressure": 11.790,
  "coolant_pressure": 3.178,
  "lub_oil_temp": 84.144,
  "coolant_temp": 81.632
}

Example Response (JSON)

{
  "prediction": 1,
  "prediction_title": "Engine Condition: Fault Detected",
  "prediction_badge": "FAULT DETECTED",
  "health_score": 44.3,
  "probabilities": {
    "normal_pct": 44.3,
    "fault_pct": 55.7
  },
  "risk": {
    "level": "MODERATE",
    "label": "Watchlist",
    "color": "#f59e0b"
  },
  "recommendations": [
    "Immediate inspection required for lub oil temp: Oil overheating!",
    "Monitor Fuel pressure: Fuel pressure is elevated."
  ]
}

cURL Command

curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"engine_rpm": 700, "lub_oil_pressure": 2.49, "fuel_pressure": 11.79, "coolant_pressure": 3.17, "lub_oil_temp": 84.14, "coolant_temp": 81.63}'

Python Code Snippet

import requests

payload = {
    "engine_rpm": 1200,
    "lub_oil_pressure": 3.5,
    "fuel_pressure": 6.2,
    "coolant_pressure": 2.3,
    "lub_oil_temp": 77.0,
    "coolant_temp": 78.5
}

response = requests.post("http://127.0.0.1:5000/api/predict", json=payload)
data = response.json()
print("Prediction:", data["prediction_title"])
print("Health Score:", data["health_score"])
